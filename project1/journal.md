## 28/09/2026 - Prototyping variables
This prototyping project allowed me to explore a larger range of visual concepts from typography to shapes to incorporating illustrations. Variables taught me a lot about the significance of how code works, enabling me to explore more creative pathways towards these artworks.

A challenge I faced was incorporating the variable into my code. Initially, my typography movement used a sin graph, but I quickly figured it made the whole layout rather confusing. Hence, I changed to use multiple variables: an open time, hold time and close time. This quickly made the process simplier, as I only had to make open and close times the same duration for a seamless movement and transition.

What surprised me most was how a subtle shift in these numeric values led to a complete different change in each work. For example, changing the rectangle counts and frames per step heavily affected how the pattern shifting occured. 

I hope to explore more complex and abstract ideas in the future, such as possibly using variables to create moving 3D wireframes. Below attached is a project I really admire, and would love to develop my skills further to create something like this.
